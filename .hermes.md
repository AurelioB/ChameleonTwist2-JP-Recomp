Goal: native Android/arm64 APK for Chameleon Twist 2: Recompiled, using the BanjoRecomp and BMHeroRecomp Android ports as templates.

Project root: `/home/hermes/Projects/personal/ChameleonTwist2-JP-Recomp`.

## Baseline setup

Use the user-local Android/native tooling. Do not reinstall unless discovery proves it is missing or broken.

```sh
source ~/.config/android-build-env.sh
export PATH="/usr/lib/llvm-19/bin:$PATH"
```

## Shared dependency policy

Common recompilation/runtime dependencies should point at Aurelio-owned shared forks, matching BanjoRecomp and BMHeroRecomp:

- `lib/N64ModernRuntime` -> `https://github.com/AurelioB/N64ModernRuntime.git`, commit `27b20c8c80aa817be24c2a2af3d42030225bf8d7` (`audit/android-runtime-pause`)
- `lib/rt64` -> `https://github.com/AurelioB/rt64.git`, commit `2647d781a0c03486c7e373eb7b0729258292b36c` (`audit/android-sdl-vulkan`)

Nested shared RT64 dependencies already point to Aurelio forks from the shared RT64 commit where needed, including `plume` and `nativefiledialog-extended`.

## Artifact and ROM hygiene

- The JP ROM input is local dev input only. Do not commit or package ROM files.
- Generated recompilation outputs such as `RecompiledFuncs/`, APKs, CMake/Gradle build outputs, and caches should stay ignored or be cleaned before commit unless explicitly approved.
- If a dev-full APK ever packages ROM-derived generated assets, gate it clearly as local-only and verify APK contents before sharing.
